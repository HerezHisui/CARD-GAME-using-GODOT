# Abandoned classroom integration

Sources: the user-supplied `old-abandoned-classroom.zip` and `old_abandoned_classroom.glb`. The active room uses the GLB's native PBR materials, packed roughness/metallic channels, normal map, glass and authored colors. The original GLB, FBX and supplied textures are preserved byte for byte. No texture or model downsizing has been performed. The GLB's main textures were supplied at 2048×2048; that is their original resolution. The red X in the reference identifies the front-right skewed desk; it is a selection annotation, not painted onto the table.

`scripts/abandoned_classroom.gd` imports the GLB, cancels its export conversion and turns the mesh coordinates -90 degrees. The selected desk's top center is `(1.88549, 1.11895, 3.485565)` and its yaw is -13.2825 degrees. The adapter turns that desk square to the gameplay camera, scales the room by 2.5, and brings its top center to `(0, 1, 0)`. This scene transform does not change model detail or texture resolution. The original desk supports the playmat and all eight lanes. The previous procedural table remains only as a hidden, noncolliding reference node.

Native GLB materials retain their texture maps and channel assignments, with 16× anisotropic filtering for angled surfaces. Window glass admits warm directional light; a muted exterior backing prevents windows from exposing the scene background. Six textured panels close the asset's cut-away back, outer walls, floor and ceiling. These panels are decorative and never intercept card-selection rays. The original walls, windows, desks, chairs and chalkboard remain intact. A runtime emissive overlay follows only the ceiling fixture faces, leaving the source model and other white material parts unchanged.

The desktop project uses Forward+ with 4× MSAA and temporal anti-aliasing at full 3D rendering resolution. Screen-space ambient occlusion adds contact shadows; indirect light and subtle volumetric haze soften the room. HDR-only bloom targets luminous fixtures and window highlights instead of washing out card text. Sunlight comes from the window side and crosses the selected desk. A bounded local contrast/sharpness pass and restrained vignette grade the world below the HUD and menus, without intercepting input. Ambient occlusion, indirect lighting, volumetric fog and glow are enabled only with Forward+; the Compatibility renderer remains usable without those effects. The supplied files contain the model and materials, not the reference viewer's full lighting/postprocessing scene, so these settings recreate its atmosphere rather than importing an identical render.

Room, Table and Overhead views keep the existing W/S controls and eased transitions. All cameras remain within the closed room. `tests/classroom_integration_smoke.gd` checks exact desk alignment, board fit, interior camera paths, all eight slot raycasts, actual encounter play, map/deck navigation, and graphical background coverage at 16:10, 16:9 and ultrawide window sizes. `tests/visual_quality_smoke.gd` checks the original GLB checksum, original imported texture dimensions, PBR roughness channels, AA and full rendering resolution, bloom, fixture highlights, grading layer order and live battle input; it also captures cards and help text for readability review. `tests/lighting_review.gd` captures room-only views for visual comparison. Tests use disposable saves.
