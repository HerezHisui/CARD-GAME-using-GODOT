# Midnight DRRills

A school-themed card roguelike made in Godot 4.7 (GDScript). Using Preparedness cards to hold off Disaster encounters and the Janitor. Fires, earthquakes, floods and typhoons come at you, and you build up a deck as you climb the map.

All 65 cards have art inside painted frames, with idle and selected states. Spell frames have no ATK or HP. The title screen is a parallax scene. Current work is on the `main-1` branch.

## How to run

1. Install Godot 4.7.
2. Open `new-game-project/project.godot`.
3. Run the main scene.
